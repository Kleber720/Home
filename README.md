# MotionVerse · Site de Apresentação

> **Estudos e tutoriais:** este repositório reúne exercícios, prática de curso ou acompanhamento de tutoriais. Não faz parte dos quatro projetos principais do portfólio.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css&logoColor=white) ![JavaScript](https://img.shields.io/badge/JavaScript-B99000?style=flat-square&logo=javascript&logoColor=white)

Site de apresentação do projeto MotionVerse, com informações sobre o jogo, gestos de controle e equipe. Este repositório é um fork de [Erikfrvr/Home](https://github.com/Erikfrvr/Home).

## Conteúdo

- Página inicial e apresentação da história do jogo.
- Seções de mecânicas, demonstração e equipe.
- Páginas de cadastro e ranking.
- Currículos e páginas dos integrantes.
- Recursos visuais e modelos 3D carregados com `model-viewer`.

## Como visualizar

Sirva a pasta por um servidor local, como o Live Server do VS Code, e abra `index.html`. Alguns recursos externos exigem conexão com a internet.

## Organização

- `index.html`, `style.css` e `script.js` — página principal.
- `Cadastro/` e `Ranking/` — páginas complementares.
- `Curriculos/` — páginas dos integrantes.
- `GUIA-DE-ESTILO.md` — referência visual do projeto.

## Projeto relacionado

[MotionVerse](https://github.com/Kleber720/MotionVerse) reúne o jogo, o editor de fases e o site de apresentação.
